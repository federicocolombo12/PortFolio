**PulseEngine** connects live physiological telemetry (ECG/HRV, SpO2, autonomic stress) to procedural real-time graphics for Extended Reality biofeedback on standalone **Meta Quest 3**.

Instead of deforming fixed-topology polygon meshes with blendshapes, the system models living shapes as **mathematical Signed Distance Fields (SDFs)** evaluated on GPU—and bridges them directly into **Unity VFX Graph** via compute voxelization so clinicians get fluid organic motion at a locked **90 FPS**.

### Why Real-Time SDFs: The Research Pivot

The thesis started as environmental depth reconstruction on Quest 3 using Meta's Depth API and point-cloud reprojection. Early benchmarks showed that open tools like `QuestRoomScan` and `UnityGaussianSplatting` already solved static room capture—continuing there meant reinventing an existing wheel.

The unsolved problem for our trauma-therapy scenario was representing **continuous autonomic arousal** (mapping calm parasympathetic rest vs. sympathetic stress along the cross-modal **Bouba ↔ Kiki** spectrum). Polygon meshes break or self-intersect when geometry needs to smoothly swell, split, and sprout spikes under erratic sensor input. Switching to analytical HLSL raymarching gave the visuals infinite topological freedom without vertex topology limits.

### Mental Model for Live Signals: The Virtual DAW Mixer

When designing how to manage multiple noisy real-time biosignals (OSC, WebSockets, Serial microcontrollers, BLE wearables) at once, wiring packet parsers straight into shader uniforms immediately turns into unmaintainable glue code.

I pictured the problem like mixing live audio tracks in a studio, and built **`DAWMixerWindow`** directly inside Unity:

- **Channel Strips per Sensor:** Each incoming stream gets gain/smoothing sliders, live OLED oscilloscopes, VU meters, and **Solo [S] / Mute [M]** switches so a clinician or tech artist can isolate a noisy sensor mid-session without dropping network state.
- **Packet Sniffer & Snapshots:** Auto-detects incoming telemetry keys for 1-click binding, and serializes full routing states into `ScriptableObject` snapshots for clinical session recall.

### Hierarchical GPU CSG & Fixing the 180° Symmetry Seam

Taking workflow cues from MudBun, SDF primitives evaluate in Unity sibling order (`Smooth Union`, `Smooth Subtraction`, `Smooth Intersection` with per-node softness), modulated by bounded `SdfModifierVolume` domains (twist, bend, bounded 3D noise with inner/falloff gizmos). Asymmetric exponential damping (`tau ≈ 2.5s`) prevents jarring visual jumps during patient down-regulation.

**Bug Caught — Triplanar Normal Inversion:** Because implicit SDFs have no UVs, surface detail uses object-space triplanar projection. Naive triplanar normal blending relies on Cartesian axis sign flips, which caused 180° inverted normal seams along `X=0`, `Y=0`, and `Z=0` whenever organic geometry morphed through origin planes. Replacing it with **Morten Mikkelsen's Surface Gradient** (`∇_surf(h) = ∇h - (N · ∇h)N`) keeps micro-relief tangent to the true implicit gradient with `C¹` continuity across all axes.

### Breaking Quest 3's Fill-Rate Wall: Compute Voxelizer -> VFX Graph

Full-screen raymarching at Quest 3 native resolution (`2064 × 2208` per eye) hit `7.84 ms` GPU (`72.1 FPS`)—too tight to guarantee zero motion sickness under clinical workloads.

To break the fragment bottleneck without giving up runtime CSG morphing, I decoupled **field evaluation** from **rendering**:

1. **`SdfVolumeVoxelizer` (Compute Shader, `8×8×8` thread groups):** Evaluates the CSG tree and modifier stack once per frame into a 3D `RGBAHalf` `RenderTexture` (`32³` / `64³` / `128³`) in **under 0.8 ms**, storing metric distance in `.r` and interpolated color in `.gba`.
2. **VFX Graph Integration (`ConformToSDF`):** Samples that live 3D volume directly inside Unity Visual Effect Graph so particle swarms flow, adhere, and recolor dynamically against changing implicit geometry.
3. **Physics-Only Mode:** On standalone XR, the full-screen fragment raymarching pass turns off completely while the compute SDF keeps driving GPU particles—delivering a **61.3% GPU frame time reduction**.
