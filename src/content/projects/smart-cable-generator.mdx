**Smart Cable Generator** is a Python-based add-on I developed for Blender to automate and speed up the set-dressing process for 3D environments, specifically targeting sci-fi and cyberpunk aesthetics.

### The Problem
When building complex environments, artists often spend hours manually drawing bezier curves to create hanging cables, power lines, and vines between different modular assets (e.g., connecting a roof antenna to an AC unit). This process is slow, tedious, and destructive if the buildings are moved. 

### The Solution
I engineered a procedural generation tool using Blender's `bpy` and `bmesh` APIs. The tool allows artists to enter Multi-Object Edit Mode, select any two vertices across entirely different meshes, and instantly generate a fully parameterized 3D cable connecting them.

### Features & Technical Implementation

- **Distance-Based Parabolic Gravity:** Instead of relying on heavy physics simulations, the tool calculates the true 3D distance between the points and applies a mathematical parabolic curve (`4 * sag * t * (1-t)`) to simulate realistic weight and gravity. This ensures that the cable sag scales correctly whether the buildings are 10 meters or 1 kilometer apart.
- **Multi-Object BMesh Integration:** The script scans `bpy.context.objects_in_mode` to allow selection across different modular assets simultaneously, translating local vertex coordinates into global space via matrix multiplication (`matrix_world @ v.co`).
- **Custom UI & Presets:** I built a native UI panel in Blender's sidebar that exposes parameters like Thickness, Resolution, and Gravity Sag. It includes predefined presets (e.g., *Thick Power Cable*, *Thin Wire*, *Droopy Vine*) and a material picker to automatically assign shaders to the generated splines upon creation.
