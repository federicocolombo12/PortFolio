### Act 1: Social Competitive Friction & Behavioral UX Strategy

Informal table tennis leagues in clubs, studios, and campuses suffer from four recurring failure modes that cause casual groups to abandon tracking:

1. **Table-Side Score & Serve Disputes:** Without an authoritative shared scoreboard, players waste time arguing over serve rotation, deuce calls, or forgotten match outcomes.
2. **Bottom-of-Table Tilt & Churn:** Once a player falls behind in a pure Elo ladder, every loss hurts motivation—leading them to stop playing top seeds or quit the group.
3. **Context-Blind Ratings:** A serious derby match and a casual windy outdoor game with a borrowed paddle are rarely equivalent.
4. **Spectator Disengagement:** Players waiting off-table lose interest between rotations.

To eliminate these friction points, I structured **EloPingPong Arena** around four tightly coupled UX mechanisms:

* **Frictionless Private-League Onboarding & Dual Ladder:** Players join an isolated club via a 6-character invite code (`SPIN26`), competing simultaneously on the **Absolute Elo Ladder** and a **Seasonal ATP Race** (which rewards match volume and tight defeats, preventing bottom-table drop-off) alongside a self-deprecating **Wooden Spoon** comedy box.
* **Table-Side Guard vs. Spectator Referee:** A full-screen one-handed live scoreboard syncs score, serve rotation, deuce rules (`10-10+`), and 1-tap telemetry (*Smash, Ace, Defense, Edge, Net, Style*) across every spectator device in real time.
* **Anti-Biscotto Spectator Economy:** Sidelined players wager virtual *LUL Coins* across **5 live dynamic markets** or place **WANTED Bounties** on rivals—while an active on-table player is strictly locked to betting only on their own win.
* **Zero Pay-to-Win Retention:** All coins and **8 × 6-tier retroactive achievements** (*Legno* through *Gear 5*) unlock purely cosmetic neon/gold card auras, titles, trophies, and procedurally synthesized victory anthems.

### Act 3: Domain Engineering Highlights

#### 1. Backward-Induction DP Live Odds & Anti-Biscotto (`src/core/betting.ts`)
Pre-match wagering closes automatically once total combined points reach `6` (`PRE_MATCH_BET_CUTOFF`). During in-play rallies, `calculateLiveDynamicOdds()` evaluates exact point-by-point win probabilities over a dynamic programming table `dp[score1][score2]` anchored by the closed-form deuce geometric series `deuceProb = (p * p) / (p * p + q * q)`—yielding responsive live odds across **5 markets** (`match_winner`, `total_points`, `total_smashes`, `luck_points`, and `deuce_happens`) while enforcing **Anti-Biscotto** (active players can wager only on their own victory) and **Anti-Hedging** rules:

```ts
// Exact Markov win probability via Backward-Induction DP (src/core/betting.ts)
const rawPointProb = 1 / (1 + Math.pow(10, (p2Elo - p1Elo) / 400));
const p = Math.min(0.8, Math.max(0.2, rawPointProb));
const q = 1 - p;
const deuceProb = (p * p) / (p * p + q * q);

for (let i = targetPoints; i >= score1; i--) {
  for (let j = targetPoints; j >= score2; j--) {
    if (i >= targetPoints - 1 && j >= targetPoints - 1 && i === j) {
      dp[i][j] = deuceProb;
    } else {
      dp[i][j] = p * dp[i + 1][j] + q * dp[i][j + 1];
    }
  }
}
```

#### 2. Asymmetric Contextual Elo, Decay & Rhythm Bonus (`src/core/elo.ts`)
Rather than treating every rally identically, `calculateEloChange()` multiplies base logistic deltas by environmental tags (`wind`, `beer`, `dark`, `derby`) and asymmetric personal handicaps (`borrowed_racket`, `injured`), plus a `+15%` **Rhythm Bonus** for active players (`>= 3` matches in 5 days) and a weekly `-5` Elo **Inactivity Decay** beyond a 7-day grace period (floored at `1200`).

#### 3. Zero-Latency Procedural Web Audio & Cloud Integrity (`src/utils/soundEffects.ts`, `src/core/security.ts`)
* **Procedural Audio Synthesis:** Uses the Web Audio `AudioContext` (oscillators, frequency envelopes, noise buffers, waveshaper distortion) to synthesize tactile SFX (*Smash, Ace, Edge, Net, Wheel Tick*) and equippable victory anthems (*FFVII Fanfare, Heavy Rock, Cyber Rave, Stadium Cheer*) with **0 KB of audio file downloads**.
* **Cloud Safety & Audit Vault:** `EloContext.tsx` enforces instant spectator auto-eviction when the referee closes a live match, `sanitizePlayerUpdates()` prevents IDOR stat tampering, `sanitizePlayerTags()` strips unearned badges, and `MatchBackupVaultModal` preserves snapshots of both completed and cancelled live matches.
