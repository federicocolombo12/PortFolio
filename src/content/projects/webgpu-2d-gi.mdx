### Frame Render Graph: 15 Compute Dispatches + 1 Render Pass

Every frame runs on a `512×512` `rgba16float` HDR pipeline organized as **15 compute dispatches** followed by a single bufferless fullscreen render pass (`draw(3)`), updating `262,144` texels cleanly without VRAM reallocation:

#### Explicit Bindings & Command-Encoder Constraints
- **64-Byte Aligned Uniform Buffer:** Packs `resolution`, `mouse`, `prevMouse`, `brushRadius`, `isDrawing`, `brushColor`, `brushMode`, `clearRequested`, `activePass`, and `frameIndex` for deterministic GPU reads.
- **9 Separate `jfaStepBuffers` (16 B each):** Because a WebGPU `GPUCommandEncoder` records compute dispatches asynchronously before `queue.submit()`, mutating a single uniform buffer between JFA passes would make all 9 dispatches observe only the last written `stepSize`. Binding 9 distinct buffers cleanly preserves `stepSize ∈ {256, 128, 64, 32, 16, 8, 4, 2, 1}`.

### Stage 1 & 2: Ping-Pong Canvas, JFA Flood & Live Euclidean SDF

The scene stores geometry and HDR lighting inside a single `rgba16float` buffer encoded via alpha convention: `0.0` for empty air, `1.0` for occluding walls, and `2.0` for emissive neon emitters (`brushColor.rgb * 2.5`).

1. **`paint.wgsl` (`@workgroup_size(8, 8)`):** Evaluates capsule signed distance (`sdSegment`) between `prevMouse` and `mouse` so fast cursor drags draw solid, gap-free strokes—with `max(dot(ba, ba), 0.0001)` preventing division-by-zero `NaN` artifacts on static clicks.
2. **`jfa_seed.wgsl` → 9× `jfa_step.wgsl` → `sdf.wgsl`:** Converts wall and light pixels into coordinate seeds and runs parallel Jump Flooding in `O(log₂ N)` steps (`9` dispatches for `512×512`), resolving exact pixel-space distances (`9999.0` fallback when the canvas is cleared empty).

> **Real Bug Caught & Solved — Ping-Pong Desync on Clear:** During early testing, placing `textureStore` inside `if (u.isDrawing == 1u)` caused Texture A and Texture B of the Ping-Pong pair to diverge whenever `Clear Scene` fired, blinking alternating old/empty frames on screen. Moving `textureStore(dstTex, vec2<i32>(id.xy), val)` unconditionally at the end of `main` kept both surfaces locked in sync every frame.

```wgsl
// jfa_step.wgsl — 3×3 neighborhood flooding at stepSize ∈ {256..1}
for (var dy = -1; dy <= 1; dy += 1) {
  for (var dx = -1; dx <= 1; dx += 1) {
    let sampleCoord = vec2<i32>(id.xy) + vec2<i32>(dx, dy) * jfa.stepSize;
    if (sampleCoord.x < 0 || sampleCoord.x >= i32(u.resolution.x) ||
        sampleCoord.y < 0 || sampleCoord.y >= i32(u.resolution.y)) {
      continue;
    }
    let candidate = textureLoad(srcJfaTex, vec2<u32>(sampleCoord), 0);
    if (candidate.z > 0.5) {
      let d = length(myPos - candidate.xy);
      if (d < bestDist) { bestDist = d; bestSeed = candidate; }
    }
  }
}
```

### Stage 3: Stratified Sphere-Traced GI, Indirect Bounce & Temporal EMA

Once the live SDF is built, `gi.wgsl` marches `16` stratified jittered rays per empty pixel (up to `32` sphere-tracing steps each) driven by a decorrelated **PCG Hash RNG**:

```wgsl
// gi.wgsl — Stratified Monte Carlo raymarching + 1-bounce color bleeding
let seed = (id.x * 1973u) ^ (id.y * 9277u) ^ (u.frameIndex * 26699u);
var accum = vec3<f32>(0.0);

for (var i = 0u; i < 16u; i++) {
  var pos = vec2<f32>(id.xy) + 0.5;
  let angle = (f32(i) + rand(seed + i * 747796405u)) / f32(16u) * 6.2831853;
  let dir = vec2<f32>(cos(angle), sin(angle));

  for (var j = 0u; j < 32u; j++) {
    if (pos.x < 0.0 || pos.x >= u.resolution.x || pos.y < 0.0 || pos.y >= u.resolution.y) { break; }
    let d = textureLoad(sdfTex, vec2<i32>(pos), 0).r;
    if (d < 1.0) {
      let hit = textureLoad(sceneTex, vec2<i32>(pos), 0);
      if (hit.a >= 1.5) {
        accum += hit.rgb;
      } else if (hit.a >= 0.5 && u.clearRequested == 0u && u.frameIndex > 1u) {
        let bouncePos = clamp(vec2<i32>(pos - dir * 2.0), vec2<i32>(0), vec2<i32>(u.resolution) - vec2<i32>(1));
        accum += vec3<f32>(0.42, 0.46, 0.54) * textureLoad(historyTex, bouncePos, 0).rgb;
      }
      break;
    }
    pos += dir * max(d, 1.0);
  }
}
```

#### Engineering Pitfalls Solved in `gi.wgsl` & `temporal.wgsl`
- **Ray State Leak & RNG Correlation:** An initial draft declared `var pos` outside the `i` ray loop and reused `seed` unchanged per ray, causing rays `1..15` to start buried inside the wall hit by ray `0` and producing coherent diagonal banding. Resetting `pos` per ray and permuting with `seed + i * 747796405u` restored clean isotropic Monte Carlo noise.
- **1-Bounce Indirect GI in Screen Space:** Sampling `historyTex` directly at `pos` returned near-black wall pixels (`vec3(0.02, 0.025, 0.035)`). Stepping slightly back into free air (`pos - dir * 2.0`) via a dedicated bind-group layout (`threeTexToStorageLayout`) reads the previous frame's incident irradiance right in front of the surface, producing genuine **diffuse color bleeding** modulated by `wallAlbedo = vec3(0.42, 0.46, 0.54)`.
- **Adaptive Temporal EMA (`temporal.wgsl`):** Blends raw GI with history at `alpha = 0.08` when static for smooth noise-free convergence, `0.35` while actively painting strokes to prevent ghosting trails, and `1.0` on reset.

### Stage 4: Workgroup Shared-Memory Bloom & AgX Pass Inspector

To keep the post-process pipeline memory-bandwidth friendly, `bloom.wgsl` runs 4 separable compute passes (`blur_h` → `blur_v` → `blur_h` → `blur_v`, `RADIUS = 8`, `sigma ≈ 4.0`). Rather than triggering 17 global VRAM reads per pixel, all 64 threads in a workgroup cooperatively stream a contiguous **80-pixel strip** (`TILE_SIZE = 64u + 2 × 8` apron) into fast on-chip SRAM (`var<workgroup> tile: array<vec3<f32>, 80>`), extracting bright HDR emissives softly above luminance `0.85` on the initial horizontal pass only:

```wgsl
// bloom.wgsl — Uniform control flow compliant shared-memory strip loader
for (var i = lid; i < SHARED_LEN; i += TILE_SIZE) {
  let sx = clamp(x0 + i32(i), 0, i32(u.resolution.x) - 1);
  var c = textureLoad(srcTex, vec2<i32>(sx, y), 0).rgb;
  if (params.extractBright == 1u) {
    let luma = dot(c, vec3<f32>(0.2126, 0.7152, 0.0722));
    let soft = max(luma - 0.85, 0.0) / max(luma, 1e-4);
    c = c * soft;
  }
  tile[i] = c;
}
workgroupBarrier(); // Must run under uniform control flow BEFORE bounds return!
if (gid.x >= u32(u.resolution.x) || gid.y >= u32(u.resolution.y)) { return; }
```

- **WebGPU Uniform Control Flow Compliance:** Placing `if (gid.x >= res.x) { return; }` before `workgroupBarrier()` violates WebGPU's uniform control-flow validation to protect against workgroup deadlocks. Deferring the out-of-bounds return until after the barrier guarantees every thread participates in shared loading cleanly.
- **AgX Double-Gamma Fix & 5-Stage Pass Inspector (`display.wgsl`):** The final bufferless render pass switches live between **5 intermediate buffers** (`1. Scene Input`, `2. JFA Voronoi Seeds`, `3. Live SDF`, `4. Raw Monte Carlo GI`, `5. Temporal + Bloom + AgX`). During integration, Blender's 6th-order AgX polynomial output (already in sRGB curve space) was accidentally gamma-encoded a second time; applying `pow(max(v, 0.0), 2.2)` at the end of `agxToneMapping()` cleanly aligned linear output with the unified `pow(..., 1.0 / 2.2)` display transform.
