### Frame Execution: 15 Compute Dispatches + 1 Render Pass

Every frame runs on a `512×512` `rgba16float` HDR pipeline (**15 compute dispatches** followed by one bufferless fullscreen pass `draw(3)`), updating `262,144` texels with zero per-frame VRAM reallocation:

- **`paint.wgsl` (`@workgroup_size(8, 8)`):** Encodes empty air (`0.0`), occluders (`1.0`), and HDR neon emitters (`2.0`) into alpha, using capsule distance (`sdSegment`) between `prevMouse` and `mouse` so fast drags never leave gaps.
- **`jfa_seed.wgsl` -> 9× `jfa_step.wgsl` -> `sdf.wgsl`:** Parallel Jump Flooding resolves Euclidean distances across `512×512` in 9 dispatches (`stepSize ∈ {256..1}`).
- **`gi.wgsl` & `temporal.wgsl`:** Marches `16` stratified jittered rays (`<= 32` steps each) with a PCG hash RNG, reads 1-bounce indirect color bleeding from `historyTex`, and blends temporally (`alpha = 0.08` static for clean convergence, `0.35` while painting to kill ghosting).
- **`bloom.wgsl` & `display.wgsl`:** Four separable compute blur passes (`RADIUS = 8`) load an **80-pixel strip** (`64 + 2×8` apron) into `var<workgroup>` SRAM per workgroup before exposing all 5 pipeline stages in a live Pass Inspector.

### Five Real WebGPU / Shader Bugs Caught & Solved

1. **Async Command Encoder Overwriting `stepSize`:** Mutating one uniform buffer between the 9 JFA dispatches caused all passes to observe only the final `stepSize = 1` once `queue.submit()` executed. **Fix:** allocated `9` separate 16-byte `jfaStepBuffers`, one per step size.
2. **Ping-Pong Texture Desync on Clear:** Putting `textureStore` inside `if (u.isDrawing == 1u)` caused Texture A and Texture B to diverge after pressing `Clear Scene`, flickering alternating stale frames. **Fix:** moved `textureStore(dstTex, ...)` unconditionally to the end of `paint.wgsl`.
3. **Ray State Leak & Zero Indirect Bounce:** Declaring `var pos` outside the 16-ray loop reused hit coordinates buried inside walls, causing coherent diagonal banding; later, sampling `historyTex` directly at wall hit `pos` returned near-black wall texels (`vec3(0.02, 0.025, 0.035)`). **Fix:** reset `pos` per ray with permuted seeds (`seed + i * 747796405u`) and stepped back into free air (`pos - dir * 2.0`) before reading `historyTex`.
4. **Workgroup Barrier Deadlock Validation:** Returning out-of-bounds threads (`if (gid.x >= res.x) { return; }`) *before* `workgroupBarrier()` failed WebGPU's uniform control-flow validator. **Fix:** placed the shared-memory strip load before the barrier and deferred the bounds return until afterward:

```wgsl
// bloom.wgsl — Uniform control-flow compliant SRAM strip loader
for (var i = lid; i < SHARED_LEN; i += TILE_SIZE) {
  let sx = clamp(x0 + i32(i), 0, i32(u.resolution.x) - 1);
  tile[i] = loadThresholded(sx, y, params.extractBright);
}
workgroupBarrier(); // All workgroup threads MUST reach the barrier before returning
if (gid.x >= u32(u.resolution.x) || gid.y >= u32(u.resolution.y)) { return; }
```

5. **Double Gamma Encoding on AgX:** The 6th-order AgX polynomial output already sits in sRGB curve space, so the final `pow(..., 1.0 / 2.2)` display transform washed out shadows. **Fix:** applied `pow(max(v, 0.0), 2.2)` inside `agxToneMapping()` to keep linear/display spaces aligned.
