### Research, Heuristics & Prototyping

Built from semi-structured interviews with 5 target participants (3 students aged 12–18, 2 math teachers), turning scattered home study into short timed challenge sprints, granular error review, and teacher/peer study sheets gated behind Level 10 verification.

Before coding, we validated low-fi paper flows and Mid-Fi Figma prototypes ([Challenge Flow](https://www.figma.com/proto/UDJMeTzzTuGo86RtADNy18/Pagina-Sfida?node-id=2-615&node-type=canvas&t=lE3R2y6LwT4AhbOo-1&scaling=scale-down&content-scaling=fixed&page-id=0%3A1&starting-point-node-id=2%3A615) · [Profile Flow](https://www.figma.com/proto/FKMP5JMc0gD6bJ407JDYRf/Pagina-Profilo?node-id=1-2&starting-point-node-id=1%3A2&t=00hHRhxwoHHTi9tf-1)) against **5 independent Nielsen Heuristic Evaluations**, shifting to Mobile-First and replacing hidden overflow menus with explicit progress indicators (`1/10`) and exit confirmations.

### React Native / Firebase Implementation

Built in **React Native + Expo (`~52`) + TypeScript + Firebase RTDB** with `useReducer`/`StateContext`, math equation rendering (`react-native-math-view`), 3 per-challenge power-ups (`+30 secondi`, `Doppio tentativo`, `Mostra Grafico`), speed-weighted XP leveling (`5,000 XP/level`), inline question bug reporting, and verified study-sheet uploads.

*(Prototype scope note: 3 core challenges, XP/levels, badge unlocks, question reports, and Level 10 verification sync live with Firebase; explore cards, classroom podium, and scheduled challenge views use local placeholder fixtures.)*
