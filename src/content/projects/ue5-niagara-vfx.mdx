Built as an interactive VFX layer on top of the procedural UE5 environment, this study pairs multi-emitter **Niagara particle systems** with **Blueprint user-parameter injection** so projectiles track moving targets mid-air and trigger real-time Lumen lighting feedback on impact.

### 1. Ambient Field System (Wisps & Wind Petals)

- **Spline-Scaled Orbs:** Main emitters drive glowing sprites whose radius and color gradient decay along lifespan curves.
- **Niagara Light Renderer:** Couples dynamic point lighting directly to particle emissive intensity, illuminating nearby grass and rock in Lumen without manually placed point lights.
- **Drifting Petals:** Secondary GPU emitter reacting to wind vector fields across the clearing.

### 2. Target-Seeking Comet (4 Emitters + Blueprint Steering)

Rather than animating the projectile along a fixed spline, the comet steers dynamically toward any runtime Actor:
1. A Blueprint reads the target Actor's world location each tick and updates an exposed **`User.TargetPosition` (`Vector3`)** parameter on the Niagara component.
2. Inside the emitter stack, a **Point Attraction Force** pulls particle velocity toward `User.TargetPosition`, bending the trajectory dynamically in 3D space.
3. Four synchronized emitters split the visual layers: **Core Light Head**, **Dual Light/Dark Ribbon Trails**, **Collision Flash Burst**, and **Physical Impact Sparks**.
