### Act 1: The Raw 3DGS Bottleneck & The Vision

3D Gaussian Splatting represents captured 3D scenes as millions of overlapping, ellipsoidal Gaussians defined by 3D position vectors, covariance scaling matrices, rotation quaternions, opacities, and spherical harmonic (SH) radiance coefficients. While this reconstructs real-world lighting faithfully, raw captures suffer from characteristic high-frequency "needle-cloud" artifacts and resist artistic stylization.

In high-end film pipelines, non-photorealistic treatments traditionally require complex offline Houdini SOP networks or custom custom C++ rasterizers. My goal was to create an artist-friendly, real-time environment within **Blender 5.3 Beta** where artists can manipulate Gaussian geometry and radiance parameters interactively:

1. Transform discrete mathematical ellipsoids into **directional, tactile brushstrokes** (Watercolor, Impasto, Gouache).
2. Compute **surface-conforming tangent flow fields** that align strokes naturally along organic contours.
3. Apply real-time edge-preserving **Kuwahara filtration and paper fiber textures** via the EEVEE-Next Viewport Compositor.
4. Package the mathematics into an **ergonomic Blender Python Add-on (`stylized_splats_addon`)** with 1-click artistic presets.

### Act 2: Native OpenUSD PointCloud Ingestion

Previous attempts to ingest 3DGS data into Blender relied on crude workarounds: spawning millions of instanced quad meshes or point cloud hacks that saturated the CPU-GPU bus and crippled viewport framerates below 10 FPS.

```
       [Raw 3DGS Capture (.ply / .splat)]
                       │
                       ▼
         [OpenUSD Converter Toolchain]
                       │
                       ▼
       [Blender 5.3 Native PointCloud (.usdc)]
     (ParticleField3DGaussianSplat Schemas)
                       │
                       ▼
        [StylizedSplatModifier (GeoNodes)]
    ├── Covariance Anisotropic Scaling
    ├── Tangent & Curl Vector Deformation
    └── Radiance Base Delighting Pass
                       │
                       ▼
       [Real-Time EEVEE-Next Viewport]
     (Anisotropic Kuwahara Compositing @ 60 FPS)
```

Blender 5.3 Beta introduced first-class support for native **OpenUSD PointCloud primitives** via the `ParticleField3DGaussianSplat` schema. Instead of generating polygon instances, Blender retains the raw point cloud memory buffer directly on the GPU.

By binding our custom modifier stack (`StylizedSplatModifier`) directly to this native point cloud primitive, we gain direct, zero-overhead access to per-point covariance attributes (`scale`, `rotation`, `color`, `opacity`) through Geometry Nodes fields without CPU readback bottlenecks.

### Act 3: Geometry Nodes Tangent Flow & Anisotropic Math

To achieve a convincing painterly look, strokes cannot simply be random billboards; they must flow across surfaces like an artist's brush following form.

#### Tangent Vector Field Formulation
Given surface normal vectors `N` extracted from the Gaussian covariance orientation, we project a 3D procedural curl noise field `V_curl` onto the tangent plane:

```glsl
T = normalize(V_curl - dot(V_curl, N) * N);
```

#### Anisotropic Covariance Scaling
We then reshape the isotropic Gaussian ellipsoids into elongated brush stroke stamps. By multiplying the primary scale axis along `T` while flattening the orthogonal cross-section:

```glsl
S_prime = vec3(sx * lambda_stretch, sy * lambda_width, sz * lambda_depth);
```

Where `lambda_stretch` ranges from `2.5x` to `8.0x` depending on stroke velocity and brush wetness. A dynamic curl noise vector offset modulates point positions over time to create organic kinetic vibration and hand-painted stroke dispersion.

### Act 4: Viewport Compositing & Kuwahara Filtration

While Geometry Nodes re-engineers Gaussian geometry, the painterly cohesion is completed in the **EEVEE-Next Viewport Compositor**:

1. **Edge-Preserving Anisotropic Kuwahara Filter:** Divides the sampling window into 8 directional sectors, calculating the mean and variance of each sector. Choosing the color from the sector with the lowest variance flattens high-frequency splat noise while preserving crisp boundary contours.
2. **Sobel Ink Contours:** A luminance gradient pass detects sharp silhouette edges and overlays fine graphic pencil/ink outlines.
3. **Paper Grain & Tactile Normal Interaction:** A high-frequency uncompressed watercolor cold-press paper normal map modulates the final luminance, grounding the virtual rendering in physical paper texture.
