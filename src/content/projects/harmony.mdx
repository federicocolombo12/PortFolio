### 1. Voice-Driven VFX Graph & Cymatics SDF Architecture

The visual core of Harmony is powered by Unity's **VFX Graph**, driven by a custom C# interface that translates live acoustic telemetry into GPU parameters without garbage collection or thread contention.

    <h4 style={{ color: '#38bdf8', marginTop: 0 }}>Cymatics 3D Texture SDFs</h4>
    <p style={{ fontSize: '0.9rem', color: '#cbd5e1', lineHeight: '1.5', margin: 0 }}>
      Rather than conventional particle emitters, we baked <strong>7 distinct 3D Signed Distance Fields (Texture3D)</strong> derived from physical Cymatics patterns (Chladni acoustic resonance geometries). The VFX Graph samples these SDFs to confine millions of particles to pure harmonic geometry.
    </p>
  </div>
  <div style={{ background: 'rgba(255,255,255,0.03)', padding: '1.25rem', borderRadius: '12px', border: '1px solid rgba(255,255,255,0.08)' }}>
    <h4 style={{ color: '#38bdf8', marginTop: 0 }}>Continuous Morphing & Scale LERP</h4>
    <p style={{ fontSize: '0.9rem', color: '#cbd5e1', lineHeight: '1.5', margin: 0 }}>
      To eliminate harsh popping when switching octave registers or fallback meshes, <code>VfxAudio_Interface.cs</code> executes a frame-by-frame vector LERP (<code>currentSdfScale → targetSdfScale</code>), smoothly transitioning the volumetric bounds while rotating on the yaw axis.
    </p>

#### Real-Time Audio Telemetry Bindings:
- **`Intensita` (Amplitude):** Inverted/remapped via LASP auto-gain to modulate particle turbulence, point size, emission rates, and core brightness.
- **`Frequenza` (Pitch):** Normalizes fundamental singing frequencies (80 Hz – 400 Hz) via `InverseLerp` to shift chromatic color palettes and noise octaves.
- **`Nota` & `Ottava`:** Chromatic note index (1–12) mapped to HSV color ramps and octave index routing directly to specific Cymatics 3D Texture SDF assets.
- **`PitchDistance` with Soft-Clamping Deadband:** Implemented a custom mathematical deadband (`safePitchDistanceClampingTreshold`) with sign restoration. When the singer wavers off-pitch, the system injects subtle, organic vibrational perturbations without jittering.

```csharp
// Excerpt from VfxAudio_Interface.cs: Soft-clamping pitch deadband logic
if (absDistance > safePitchDistanceClampingTreshold)
{
    float distanceOverThreshold = absDistance - safePitchDistanceClampingTreshold;
    float sign = Mathf.Sign(safePitchDistance); 
    finalDistance = distanceOverThreshold * sign * safePitchDistanceMultiplier;
}
vfx.SetFloat(pitchDistanceProperty, finalDistance);
```

### 2. VR Hand Collider & Particle Physical Dispersion

To ensure presence within Virtual Reality, players needed to physically touch and disturb the light they generated with their voices.

<div style={{ background: 'rgba(15, 23, 42, 0.6)', padding: '1.5rem', borderRadius: '12px', border: '1px solid rgba(56, 189, 248, 0.2)', margin: '1.5rem 0' }}>
  <h4 style={{ color: '#38bdf8', marginTop: 0 }}>Coordinate Space Transformation Pipeline (`VfxHandController.cs`):</h4>
  <ul style={{ color: '#cbd5e1', fontSize: '0.92rem', lineHeight: '1.6', paddingLeft: '1.2rem', margin: 0 }}>
    <li><strong>Runtime Node Detection:</strong> Automatically discovers tracked OpenXR palm joints (<code>R_Palm</code> and <code>L_Palm</code>) as player hands enter tracking volumes.</li>
    <li><strong>World-to-Local Vector Projection:</strong> Transforms global palm positions into the local coordinate frame of the VFX Graph using <code>vfx.transform.InverseTransformPoint(palmPosition)</code>, guaranteeing accurate collision even when the particle orb rotates or moves in 3D space.</li>
    <li><strong>Blackboard Parameter Feeding:</strong> Transmits <code>HandPosition_R</code>, <code>HandPosition_L</code>, and <code>HandRadius</code> directly to the VFX Graph, where spherical vector field forces repel and disperse particles around the player's hands in real time.</li>
  </ul>
</div>

```csharp
// Excerpt from VfxHandController.cs: Local space hand collision projection
if (rightHand != null)
{
    Vector3 posR = vfx.transform.InverseTransformPoint(rightHand.position);
    vfx.SetVector3("HandPosition_R", posR);
}
if (leftHand != null)
{
    Vector3 posL = vfx.transform.InverseTransformPoint(leftHand.position);
    vfx.SetVector3("HandPosition_L", posL);
}
vfx.SetFloat("HandRadius", handRadius);
```

### 3. Radial Procedural Achievement & Memory System

Spontaneous vocal creation is paired with a persistent reward loop: as players discover unique note-and-shape harmonies, the system records them and spawns interactive memory pedestals in a circular constellation surrounding the player.

#### Multi-Target Hand Collision on Memories:
Each spawned pedestal operates its own `SingleTrophyControl.cs` script. When the player approaches a previously unlocked vocal memory, the script tracks palm proximity and feeds local coordinates into the trophy's VFX Graph, allowing the player to reach out and physically touch, swirl, and disperse their past vocal creations.
