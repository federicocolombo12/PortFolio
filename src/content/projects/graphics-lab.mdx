### Pipeline Architecture & Stack

The renderer decouples asset loading (`Assimp` + `stb_image`), camera math (`GLM` / `GLFW`), and cross-platform CMake targets from two rendering executables sharing the core math/shader layer: a two-pass deferred PBR rasterizer and an analytical SDF raymarcher (`01_Raymarcher`).

### Deferred G-Buffer Packing (3x `GL_RGBA16F`)

Instead of allocating 5–6 full-screen float render targets for Position, Normal, Albedo, Roughness, Metallic, and AO, I packed all six material/geometric attributes into **three `GL_RGBA16F` attachments**, cutting ~33% of G-Buffer memory bandwidth:

| Render Target | Format | RGB Channels | Alpha Channel (`.a`) |
| :--- | :--- | :--- | :--- |
| **`gPositionAO`** (`COLOR_ATTACHMENT0`) | `GL_RGBA16F` | World Position (`FragPos`) | Ambient Occlusion (`ao`) |
| **`gNormalRoughness`** (`COLOR_ATTACHMENT1`) | `GL_RGBA16F` | World Normal (`N`) | Roughness (`roughness`) |
| **`gAlbedoMetallic`** (`COLOR_ATTACHMENT2`) | `GL_RGBA16F` | Linear Albedo (`albedo`) | Metallic (`metallic`) |

```glsl
// pbr_light.frag — Unpacking 6 physical inputs from 3 MRT samplers
vec4 posAO       = texture(gPositionAO, TexCoords);
vec4 normRough   = texture(gNormalRoughness, TexCoords);
vec4 albedoMetal = texture(gAlbedoMetallic, TexCoords);

vec3  FragPos   = posAO.rgb;
float ao        = posAO.a;
vec3  N         = normalize(normRough.rgb);
float roughness = normRough.a;
vec3  albedo    = pow(albedoMetal.rgb, vec3(2.2)); // sRGB -> linear
float metallic  = albedoMetal.a;
```

### Shading Passes: Cook-Torrance PBR, SPOM & Analytical Raymarching

- **Cook-Torrance BRDF:** Standard microfacet formulation (`Trowbridge-Reitz GGX` NDF, `Smith Schlick-GGX` geometry occlusion, `Fresnel-Schlick` with `F0 = mix(vec3(0.04), albedo, metallic)` and energy-conserving diffuse attenuation `kD *= 1.0 - metallic`). Full GLSL implementation lives in `pbr_light.frag` on GitHub.
- **Silhouette Parallax Occlusion Mapping (SPOM):** Implemented Natalya Tatarchuk's SIGGRAPH 2006 silhouette method (`g_buffer_pom.frag`) to get brick/stone relief on a low-poly quad without tessellation. The view ray marches `8` to `32` dynamic steps (`mix(32.0, 8.0, abs(viewDir.z))`) in Tangent Space, refines via linear intersection weight, and runs `discard` when displaced UVs exit `[0.0, 1.0]` so silhouettes clip cleanly against neighboring fragments.
- **Analytical SDF Target (`01_Raymarcher`):** Separate screen-quad pass evaluating sphere tracing on primitive CSG (`min`/`max` union, intersection, difference) with central-tetrahedron normal gradients.

### Real OpenGL / C++ Bugs Caught (`PROJECT_MEMORY.md`)

1. **OpenGL Texture Unit Leakage (Rainbow Sub-Meshes):** Untextured sub-meshes inside multi-material models left `GL_TEXTURE0` bound to the previous frame's G-Buffer World Position attachment, sampling 3D coordinates as RGB albedo. **Fix:** explicitly unbound active samplers after each draw call in `Model.cpp` and added a `hasTexture` uniform fallback.
2. **Missing Normals Turning Meshes `NaN` Black:** Sub-meshes exported without normal attributes evaluated to `vec3(0.0)`, where `normalize(vec3(0.0))` returned `NaN` across the G-Buffer. **Fix:** enforced `aiProcess_Triangulate | aiProcess_GenSmoothNormals | aiProcess_FlipUVs | aiProcess_CalcTangentSpace` on Assimp import.
3. **FBX Windows Path Crashes on macOS:** Production FBX assets embedded workstation paths like `D:\Projects\...\Cerberus_A.tga`, crashing asset lookup on POSIX filesystems. **Fix:** wrote a filename/relative path sanitizer in `Model.cpp` normalizing `\` separators relative to the asset directory.
4. **6DOF Camera Gimbal Lock:** Clamped pitch to `±89.0f` in `Camera.cpp` before computing `cross(Front, Up)` to prevent zero-length view vectors at poles.
